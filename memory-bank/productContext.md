# Product Context

## Why This Project Exists
Most neuroscience textbooks either:
- Catalog brain regions and neurotransmitters without explaining mechanisms
- Use metaphors that obscure rather than illuminate
- Assume prior biology/neuroscience coursework
- Treat biological "messiness" as inconvenient detail

This book fills the gap for technical readers who want to understand the brain as an engineered system — with all its constraints, trade-offs, and design rationale.

## Problems It Solves
1. **Knowledge gap for technologists** — ML practitioners work with "neural" networks but lack understanding of actual neural computation
2. **Mechanism deficit** — popular neuroscience books tell "what" but not "why"
3. **Level confusion** — conflating molecular, cellular, and cognitive explanations
4. **Idealized models** — ignoring noise, energy costs, and failure modes that shape real neural systems

## How It Should Work
- **Main book**: Dense, mechanism-focused chapters read sequentially
- **Companion volume**: Active learning through summaries, diagrams, exercises, and computational modeling
- **Dual formats**: Word for editorial collaboration, PDF for review and print

## User Experience Goals
Readers should finish each chapter with:
- Clear mechanistic understanding of the topic
- Appreciation for biological constraints that shaped the solution
- Vocabulary to discuss the topic precisely
- Foundation for understanding subsequent chapters
